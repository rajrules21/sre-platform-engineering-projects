# Curated Short Reading List: Project 01

1. **How the Web Works: HTTP Request Lifecycle (5 min read)**
   * *Link:* https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview
   * *Key Takeaway:* Understand HTTP methods, headers, status codes, and statelessness.
2. **Systemd Essentials: Working with Services, Units, and the Journal (8 min read)**
   * *Link:* https://www.digitalocean.com/community/tutorials/systemd-essentials-working-with-services-units-and-the-journal
   * *Key Takeaway:* Learn systemctl start/stop/restart/status and how to inspect logs with journalctl.
3. **Terraform Getting Started: The Core Workflow (6 min read)**
   * *Link:* https://developer.hashicorp.com/terraform/intro/core-workflow
   * *Key Takeaway:* Master the Write -> Plan -> Apply lifecycle.
4. **Flake8 & PEP 8 Linting in CI/CD Pipelines (6 min read)**
   * *Link:* https://flake8.pycqa.org/en/latest/
   * *Error Code Catalog:* https://flake8.pycqa.org/en/latest/user/error-codes.html
   * *Key Takeaway:* Learn the anatomy of linting codes (`E9` syntax errors vs `F` logic traps) and why CI separates fatal errors from style warnings.
